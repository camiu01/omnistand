# Security & Safety Policy

## Supported Versions

Only the latest commit on the `main` branch is actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| legacy  | :x:                |

## Reporting Safety & Functional Issues

This is an open-source 3D CAD parametric project for the Omni-Stand handheld console desk stand.

While it is not compiled executable software, physical stability, load balance, and cable-bore clearances are critical: an unstable stand or an oversized cutout can let the console slip, fall, or strain its charging cable.

If you identify a geometric interference, stability issue, sharp edge, or code bug that could cause drops, cable damage, or compromise user safety:
1. Open an issue on GitHub detailing the exact parameters, modules involved, and the stability or clearance problem.
2. For severe safety-related flaws, please use a private channel first and contact the maintainer at lorenzo.camuso@gmail.com before opening a public issue.
